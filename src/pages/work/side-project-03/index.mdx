<Section title="About this project">

Small hours is a concept for a focus timer that holds one task at a time. There's no task list, no streaks and no notifications competing for attention; just a short description of what's being worked on and a timer running quietly beside it.

The interface is intentionally sparse. The question behind it is whether fewer features can make it easier to begin, and whether a calm screen helps attention stay where it's meant to be.

When a session ends, the concept offers a simple choice: continue, take a break or write a short note about where things were left.

</Section>

<Section title="What I explored">

- Designing an interface that stays out of the way once a session starts.
- Limiting the app to a single task without making it feel restrictive.
- Ending a session gently, without alarms or guilt.

</Section>
